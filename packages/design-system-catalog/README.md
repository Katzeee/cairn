# Cairn design-system catalog

This package owns the design-system review vocabulary: sections, stable page paths, descriptions, variants, applicable states, responsive behavior, accessibility guarantees, and token contracts. The React implementations live in `@cairn/ui`; host applications supply their own product screens and platform integration.

The navigation groups theme foundations, layout components, typography components, general components, editor components, and utilities. Every component family has a focused page with live examples, import and usage code, and an API reference for the root and its composable parts. Compositions and Templates show components working together without replacing their individual reference pages. Breakpoints follow available width rather than device labels, so the same rules apply to resized windows and embedded web views.

`src/component-docs.ts` owns the component families, grouping, selected specimens, documented exports, and usage examples. The UI build reads both public TypeScript entries to generate property types, required flags, implementation defaults, inherited React attributes, and related type definitions. The generated reference is build output; property tables are not maintained by hand. Add a component family here and its live specimen in `@cairn/ui` when adding a public component. An unavailable documented export fails the build.
